# 🤖 AI Resume Matcher & Cover Letter Generator (Multi-Agent System)

Автоматизированный конвейер для поиска профильных IT-вакансий, фильтрации нерелевантных предложений и генерации персонализированных сопроводительных писем с помощью мультиагентной LLM-архитектуры.

## 🚀 Ключевые особенности (Features)

* **Multi-Source Parsing:** Асинхронный сбор вакансий с сайтов (SuperJob, Habr Карьера, Remote-Job, Getmatch) и публичных Telegram-каналов без использования ключей API соцсетей (парсинг Web-зеркал).
* **Multi-Agent LLM Architecture:**
  * 🕵️ **Agent 1 (Scout):** Использует быструю и дешевую модель (`gpt-4o-mini`). Анализирует текст, отсеивает рекламу/инфоцыганство ("Фейк-контроль") и жестко оценивает % совпадения вакансии с навыками кандидата.
  * ✍️ **Agent 2 (Copywriter):** Использует флагманскую модель (`gpt-4o`). Включается только если `match_percentage >= 75%`. Пишет глубоко персонализированное сопроводительное письмо на основе аргументов от первого агента.
* **Smart Memory (Долговременная память):** Запоминает уже проверенные URL. При повторных запусках мгновенно отбрасывает старые вакансии, экономя токены и время. Проверяются только свежие публикации.
* **Bypass Protection:** Обход базовых систем защиты от парсинга (Mobile API маскировка, перехват HTTP 404 для пустых выдач).

## 🛠 Технологический стек
* **Язык:** Python 3.10+
* **Асинхронность:** `asyncio`, `aiohttp`
* **Парсинг:** `BeautifulSoup4`
* **LLM Интеграция:** `openai` (Async API), `pydantic` (Strict JSON parsing)
* **Работа с данными:** `openpyxl` (выгрузка отчетов)

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ВАШ_НИК/ai-resume-matcher-public.git
    cd ai-resume-matcher-public
    ```

2. Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```

3. Настройте переменные окружения:
    * Переименуйте `.env.example` в `.env`
    * Добавьте свой OpenAI API ключ (или совместимый аналог, например ProxyAPI)

4. Подготовьте базу:
    * Заполните `resume_template.txt` текстом вашего резюме.
    * Отредактируйте `prompt_cover_letter.txt` под ваш стиль общения.

5. Запуск поиска по сайтам:
    ```bash
    python main.py
    ```

6. Запуск мониторинга Telegram-каналов:
    ```bash
    python tg.py
    ```

Результаты (ссылки, оценка, плюсы, минусы и готовые письма) будут сохранены в файл `suitable_vacancies.xlsx`.

## 🧠 Логика работы
1. Парсеры собирают свежие HTML-страницы и API-ответы.
2. Система памяти (`checked_urls.txt`) фильтрует дубликаты.
3. LLM Scout анализирует текст и выдает строгий JSON с `match_percentage`.
4. Если вакансия подходит, LLM Copywriter генерирует письмо.
5. Данные выгружаются в Excel для удобной отправки откликов.
